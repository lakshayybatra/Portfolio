# Portfolio

This project is my personal portfolio website built using React, Vite, Tailwind CSS, and Framer Motion. It showcases my work, skills, projects, education, and contact information in a modern and interactive layout.

## What this project includes

- About section with my introduction
- Education details
- Skills and technologies used
- Project showcase with GitHub links
- Achievements and responsibilities
- Contact form for reaching out

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Framer Motion
- Three.js

## Run locally

```bash
npm install
npm run dev
```
